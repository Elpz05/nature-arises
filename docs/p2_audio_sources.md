# P2 audio sources

The new P2 clips live in `audios/p2`. The campaign music and manual power cast recordings come from the existing game.

| Game cue | Source | Edits |
| --- | --- | --- |
| `madera.wav` | Kenney, `click_001.ogg`, CC0 1.0. [Interface Sounds](https://kenney.nl/assets/interface-sounds), [Kenney's OpenGameArt upload](https://opengameart.org/content/interface-sounds) | Filtered, mixed into an original wood resonance and rendered as mono PCM. |
| `plantar.wav` | Kenney, `impactSoft_medium_000.ogg`, CC0 1.0. [Impact Sounds](https://kenney.nl/assets/impact-sounds), [mirror and license listing](https://github.com/benjosua/nimbic/blob/main/CREDITS.md) | Filtered and layered with original soil and root textures. |
| `impacto_glacies.wav` | Kenney, `impactGlass_light_000.ogg`, CC0 1.0. [Impact Sounds](https://kenney.nl/assets/impact-sounds), [mirror and license listing](https://github.com/benjosua/nimbic/blob/main/CREDITS.md) | Filtered and layered with original ice harmonics. |
| Remaining launches, impacts, alerts, and water foley | Original project synthesis | Mono PCM with short envelopes and peak headroom. |
| `ambiente_tormenta.ogg`, `ambiente_volcan.ogg`, `ambiente_ventisca.ogg` | Original project synthesis | Loop seams crossfaded and encoded in Ogg Vorbis. |
